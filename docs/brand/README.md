# The Homeostat mark

A house held at a set point: the pine silhouette, the step response cut
into it, the amber line it settles onto. Home automation is regulation
(docs/design.md, Motivation; the concept diagram), drawn as one shape.

| File | Use |
|---|---|
| `homeostat-mark.svg` | the mark on light grounds — README, docs, listings |
| `homeostat-mark-dark.svg` | the same with the house one step lighter, for dark grounds |
| `homeostat-mark-mono.svg` | one colour, the response cut through the house; takes `currentColor` — themed icons, status bars, inline glyphs |

All three are generated by `generate.py` from one geometry; edit the
numbers there, not the SVGs. The companion app's launcher and
notification drawables come from the same numbers.

## Palette

Two colours and an ink. A third would be spent on nothing.

| Token | Hex | Where |
|---|---|---|
| house | `#1F5E4A` | the mark; the brand colour wherever one is needed |
| house, dark grounds | `#2A7A61` | the same, lifted so the silhouette holds on dark |
| trace | `#F2EFE6` | the response; light surfaces |
| set point | `#E8A33D` | the line; the one accent — an `alert` on the phone, a deviation on *Now* |

Green for calm and equilibrium, deep enough to be sober; amber because a
set point is a warm thing. Deliberately not the sky blue of the
category's largest project, and not its green either: pine is the forest,
not the eco-label.

## Geometry

108-unit canvas, the same as Android's adaptive icon. House corners are
rounded by 4 units — enough to stop cutting, not enough to go soft. The
response is a cubic curve with a minimum curvature radius of 4.3, so its
7-unit stroke outlines cleanly into the cutout. In one colour the set
point passes behind the response — broken a unit short of the curve
where it crosses, gone where the response has settled onto it — because
even-odd cannot union two holes, and because that is what the colour
mark shows anyway.
